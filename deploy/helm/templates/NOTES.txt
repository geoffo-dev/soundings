   Never use devLogin on a shared or internet-facing install.
{{- if .Values.demo.seed }}
   Demo data is loaded by the {{ $fullname }}-seed hook Job (12 people, 3 projects, 45

   admin, or anyone else on the list.
{{- end }}
{{- end }}
{{- if .Values.oidc.issuer }}
   Single sign-on with {{ .Values.oidc.issuer }} (client "{{ .Values.oidc.clientId }}").
   Register these on the IdP client (Settings > Sign-in (SSO) shows them too):
{{- range .Values.baseUrls }}
     redirect URI:             {{ . }}/api/v1/auth/callback
     post-logout redirect URI: {{ . }}/login?signed_out=1
{{- end }}
   People sign in only if they match a user (pre-created by an admin, linked by
{{- if .Values.oidc.externalIdClaim }} the
   "{{ .Values.oidc.externalIdClaim }}" claim{{ if .Values.oidc.matchVerifiedEmail }} or a verified email{{ end }}){{ else }}{{ if .Values.oidc.matchVerifiedEmail }} a verified
   email){{ else }} identity only){{ end }}{{ end }}{{ if .Values.oidc.autoCreateUsers }}, or get an account at first sign-in (autoCreateUsers){{ end }}.
{{- if .Values.oidc.externalIdClaim }}
   "{{ .Values.oidc.externalIdClaim }}" MUST be an attribute only IdP admins can set.
{{- end }}
{{- if .Values.breakGlass.enabled }}
   The break-glass admin is OFF while oidc.issuer is set. In an SSO outage, run
     helm upgrade {{ .Release.Name }} <chart> -n {{ .Release.Namespace }} --reuse-values --set oidc.issuer=
   and sign in with it ({{ $breakGlass }});
   set the issuer again afterwards. Every use is audited.
{{- end }}
{{- else if .Values.breakGlass.enabled }}
   Break-glass admin (works while oidc.issuer is empty; every use is audited):
     {{ $breakGlass }}
   Then connect single sign-on, in this order:
     a. Sign in as break-glass. In Settings > Users, pre-create the real platform admins
        (with the external ID from an attribute only IdP admins can set, and/or their
        email) as platform admins. Optionally create groups and IdP mappings.
     b. Register the redirect URIs from Settings > Sign-in (SSO) on your IdP client.
     c. helm upgrade with oidc.issuer, oidc.clientId and oidc.existingSecret.
        Break-glass then switches off; the pre-created admins are linked at their
        first SSO sign-in. SSO users are never platform admins by default.
{{- else if not .Values.devLogin }}
   WARNING: no way to sign in is enabled (oidc.issuer is empty, breakGlass.enabled and
   devLogin are false). Enable breakGlass or configure oidc.*.
{{- end }}
